record_cycle

A thin summary is rejected, not silently accepted.

const MIN_SUMMARY_CHARS = 40;

if (trimmedSummary.length < MIN_SUMMARY_CHARS) {
  return {
    ok: false,
    reason: "content was lost on the way in —
      resend the full summary, don't
      shrink it to fit."
  };
}

Shrinking content to get past a gate is a bug, not a workaround.

RUN STATUSES

Five outcomes. Never just pass or fail.

STATUSWHAT IT MEANS
completedExited clean, record_cycle succeeded for the right stage
incompleteExited clean, but no successful record_cycle call was found
failedThe process itself exited with an error
canceledA human explicitly stopped the run — not a bug
orphanedpi crashed mid-run; caught by the next session's startup sweep

external-sink-gate.ts

The preview step is code-enforced, not a prose promise.

BACKGROUND SUBAGENT, NO UI

Write is blocked, always. No dialog-capable UI exists to confirm anything.

INTERACTIVE LEAD SESSION

A rejected write means content was lost on the way in — resend it, don't trim it to fit.

GET STARTED

One shot. Then it hands off to pi's own login.

git clone <repo> pi-harness
cd pi-harness
./install.sh

→ installs or updates pi itself

→ checks for sqlite3

→ copies the harness, applies patches

→ offers to launch pi right there

Credentials are the one thing it deliberately doesn't try to automate.
